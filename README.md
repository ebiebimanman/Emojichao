# Emojichao

AzooKeyなどの日本語IMEと共存する、Slack風の絵文字ショートコード補完アプリです。macOSのメニューバーで動作します。

## できること

- `:f` のように入力するとカーソルの近くに絵文字候補を表示
- EnterまたはTabで選択した絵文字に置換
- Escでキャンセル
- 日本語エイリアスにも対応（例：`:ようせい:`、`:よだれ:`）
- Jevを使った意味・文脈ベースの絵文字検索
- 通常の日本語入力やIME変換をできる限り維持

## 動作環境

- macOS 13以降
- Apple SiliconまたはIntel Mac（GitHub Releasesの正式配布版）
- Jevによる検索を使う場合は、利用者自身のJev APIキー

## インストール

1. GitHubの「Releases」から最新の `Emojichao-x.y.z.zip` をダウンロードします。
2. ZIPを展開し、`Emojichao.app` を「アプリケーション」フォルダへ移動します。
3. Emojichaoを起動します。
4. 画面の案内に従い、アクセシビリティと入力監視を許可します。
5. 権限を許可した後、一度終了してから再起動します。

正式配布物はDeveloper IDで署名し、Appleによる公証を受けます。GitHubのソースコード画面にある自動生成ZIPはアプリ本体ではありません。

## 初期設定

メニューバーアイコンから「Jev APIキーを設定…」を開き、キーを入力します。APIキーはmacOSキーチェーンに保存されます。キーがない場合も、名前が一致するローカル候補は利用できます。

「設定…」では以下を変更できます。

- Macへのログイン時に自動起動
- テキストを入力して絵文字を検索
- 文脈を判断して絵文字を自動選択

文脈検索では、入力欄から安全に読み取れる場合に限り、コロン直前の最大10文字をJevへ送信します。テキスト検索では、コロン以降の検索語を送信します。Jevの利用にはTypeSafe AIの条件が適用されます。詳細は[プライバシー情報](PRIVACY.md)を確認してください。

## 使い方

メモなどで `:iikanzi`、`:gakkari`、`:omedetou` を試してください。

- `↓`：別の候補へ移動
- `Enter` / `Tab`：決定
- `Esc`：取り消し

文脈検索で絵文字が自動入力された直後に文字を続けると、自動入力を取り消してテキスト検索へ切り替えます。自動入力された絵文字をそのまま使うときは、先にスペースを入力してください。

## 必要な権限と安全性

Emojichaoは、他のアプリでショートコードを検知して置き換えるため、アクセシビリティと入力監視の権限を必要とします。

置き換え前に画面上の対象文字を確認し、安全に確認できない場合は入力を変更しません。パスワードまたはセキュア入力欄と判断できる場所では、文脈を読み取りません。ただし、OSや対象アプリが入力欄の性質を正しく公開しない可能性もあるため、機密情報を扱う入力欄ではアプリを一時停止するか権限を無効にしてください。

## 既知の制限

- 日本語IMEが変換中の文字列は直接置換できないため、一度確定してから置換します。
- Chrome、Slack、ChatGPT、ターミナルなど、アクセシビリティの挙動が異なるアプリでは置換方式を切り替えます。
- 入力欄の内容を安全に検証できない場合、置換を中止します。
- アプリの更新後も同じ署名、Bundle ID、インストール先を維持しないと、macOSから権限の再許可を求められることがあります。

## ソースから実行する

必要なもの：macOS、Xcode、Swift 6。

```sh
swift test
sh build-app.sh
open .build/Emojichao.app
```

開発用の署名証明書がない場合はアドホック署名になります。この場合、再ビルドのたびにmacOSからアクセシビリティ、入力監視、キーチェーンの許可を再確認されることがあります。

## リリース担当者向け

配布にはApple Developer ProgramのDeveloper ID Application証明書が必要です。最初の一度だけ公証用資格情報をキーチェーンへ登録します。

```sh
xcrun notarytool store-credentials "Emojichao-Notary" \
  --apple-id "Apple Accountのメールアドレス" \
  --team-id "35L6K3N86W"
```

Apple Accountの通常のパスワードではなく、`account.apple.com`で作成したアプリ用パスワードを、コマンド実行後の入力欄へ入力します。資格情報はmacOSキーチェーンへ保存され、ソースコードやリリースファイルには含まれません。

`AppInfo.plist`のバージョンとビルド番号を更新した後、次を実行します。

```sh
sh scripts/release.sh
```

この処理はUniversal BinaryのReleaseビルド、Developer ID署名、Apple公証、チケットのステープル、Gatekeeper検証、ZIPとSHA-256チェックサムの生成を行います。生成物は `dist/` に保存されます。
